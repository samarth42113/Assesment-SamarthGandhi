# Assesment-SamarthGandhi
 Angular Assesment Application

Set up a Project

Run this commands to run an application

Step 1 : 'npm install'

Step 2 : 'ng serve'



External Libraries used

1) ng-select - To use select, multi-select, and autocomplete dropdowns.

to install a library run below command (Although, all dependent libraries will automatically installed while run 'npm install')

Step 1 : 'npm install @ng-select/ng-select'


2) ngx-pagination - It's an Angular library that simplifies the process of adding pagination to your application.

to install a library run below command (Although, all dependent libraries will automatically installed while run 'npm install')


Step 1 : npm install ngx-pagination
